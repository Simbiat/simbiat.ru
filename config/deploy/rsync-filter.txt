# File to apply rsync filter rules

# Format:
# CWRULE [PATTERN_OR_FILENAME]
# CWRULE,MODIFIERS [PATTERN_OR_FILENAME]

# Rules:
# `exclude`, `-` specifies an exclude pattern.
# `include`, `+` specifies an include pattern.
# `merge`, `.` specifies a merge-file to read for more rules.
# `dir-merge`, `:` specifies a per-directory merge-file.
# `hide`, `H` specifies a pattern for hiding files from the transfer (behave as if the file does not exist on the source)
# `show`, `S` files that match the pattern are not hidden.
# `protect`, `P` specifies a pattern for protecting files from deletion (prevents deletion on target)
# `risk`, `R` files that match the pattern are not protected.
# `clear`, `!` clears the current include/exclude list (takes no arg)
